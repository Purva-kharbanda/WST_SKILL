## Probable cause

- **Symptom:**     After clicking **Add** on the listed Roster sub-tabs, a blank white gap appears at the bottom of the page beneath the add form panel.
- **Fault:**       `WebContent/scripts/roster/roster.payRule.renderers.js:showHideContactInfoPanel` (and parallel functions in timeClocking, alternateWorkLocation, timeRounding, timeCollection) â€” `vm.showAddTemplateTab = show` runs **before** `updatePageHeight()`, so the bottom panel renders while `pageContentHeight` still reflects the full-page value; subsequent height subtraction leaves unused vertical space.
- **Trigger:**     User clicks Add on any implicated Roster tab â†’ `showHide*Panel(true)` â†’ panel `ng-if="showAddTemplateTab"` activates before `ng-style="{height: pageContentHeight}"` on the main tab container is reduced by `entityDetailsContentHeight`.
- **Consequence:** Visible blank area at page bottom; layout looks broken but data save is unaffected.

## Probable fix

> **[SKETCH]** Triage-time analysis from static read. Local working tree already implements this pattern (uncommitted). Validate in browser before merge.

- **File(s):**       Five roster renderer controllers â€” defer `showAddTemplateTab` until after `updatePageHeight()` in each show/hide bottom-panel function.
- **Change sketch:** Move `vm.showAddTemplateTab = show` from the top of the function into the `if (!show)` / `else` branches **after** the corresponding `updatePageHeight(true|false)` call. On open: shrink height first, then set `showAddTemplateTab = true`. On close: restore height first, then set `showAddTemplateTab = false`.
- **Blast radius:**  Same anti-pattern exists in ~25 other roster renderer files (`grep showAddTemplateTab = show`); scope this PR to the five tabs listed in WFM-130904 unless QA finds the gap elsewhere.
- **Migration:**     None.
- **PR scope:**      `WebContent/scripts/roster/roster.{payRule,timeClocking,alternateWorkLocation,timeRounding,timeCollection}.renderers.js` + BAT/UI manual on all five Add flows.

```javascript
// [SKETCH] â€” triage-time only

    vm.showAddTemplateTab = show;          // â† toggles panel before height adjust
```
