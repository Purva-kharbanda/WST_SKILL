## Probable cause

- **Symptom:**     `Daily Hours` text and related fields are not aligned properly on the edit form of release-to-store records.
- **Fault:**       `WebContent/ngtemplates/roster/releaseToStore/editReleaseToStore.html` — Daily/Weekly hours section uses mixed `col-md-*` grid fragments while adjacent rows use flex utility classes.
- **Trigger:**     User opens an existing release-to-store record in edit mode and the conditional contract-hours row renders.
- **Consequence:** UI looks broken/misaligned, increasing user confusion and creating a visual quality defect in production.
